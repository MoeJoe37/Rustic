# Rustic test fonts

`RusticTest-Regular.ttf`, `RusticTest-Bold.ttf`, `RusticTest-Italic.ttf` and
`RusticTestCondensed-Regular.ttf` are original fonts generated by
[`tools/generate_test_fonts.py`](../../../tools/generate_test_fonts.py). Every
outline is a simple rectangle, oval or composite of those shapes defined in
that script; no third-party font data, outlines or metrics were copied.

The fonts and the generator's output are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The
generator script itself is part of Rustic and covered by the repository
license.

They are test fixtures with deliberately distinctive metrics, not fonts for
reading text. Regenerate them with `python3 tools/generate_test_fonts.py`;
`--check` (and `tools/tests/test_generate_test_fonts.py`) verifies the
committed binaries match the script byte for byte.
