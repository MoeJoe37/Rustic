# Shaping fixture provenance

`RusticCFFTest.otf`, `RusticCFF2Test.otf`, `.woff` and `.woff2` are original
fonts generated by [generate_shaping_fonts.py](../../../../../tools/generate_shaping_fonts.py).
Their geometric outlines, advances, GSUB `fi` ligature, GPOS `AV` pair and mark
anchors were written for Rustic. These original generated font binaries are
dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The generator remains covered by the repository license.

`Arabic.ttf` and `Devanagari.ttf` are subsets of Noto Sans Arabic and Noto Sans
Devanagari, renamed **Rustic Arabic Fixture** and **Rustic Devanagari Fixture**.
[OFL-LICENSE.txt](OFL-LICENSE.txt) retains the original copyright and SIL Open
Font License 1.1. The pinned source hashes, version strings, subset ranges,
tool versions and output digests are in [manifest.json](manifest.json).

To reproduce with the exact original source files in a local directory:

```sh
python3 tools/generate_shaping_fonts.py --noto-root /path/to/pinned/fonts
```

The build does not download or use system fonts. Reproduction needs FontTools
4.61.1 and Brotli 1.1.0; subsequent generator runs reject changed source hashes.
All runtime tests use the committed binaries. The original fixture tests compare
formats, not independently generated outlines; separate native HarfBuzz results
in `tests/fixtures/shaping_reference.txt` check glyph IDs, advances and offsets.
They do not claim all shaping or text-layout conformance suites pass.
