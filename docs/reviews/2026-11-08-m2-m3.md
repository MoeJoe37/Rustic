## First M3 slice

REN-01a adds checked CSS/device geometry, bounded immutable principal-box
snapshots, a non-replaced horizontal block width algorithm and the local
`dump-boxes` command. See [LAYOUT.md](../LAYOUT.md) for contracts and next units.
The box snapshot preserves `display:contents` text inheritance and UTF-16 units,
validates live document IDs, and checks box/node/depth/text/output budgets and
cancellation. Width measurement covers auto margins, negative/over-constrained
space, containing direction, percentages/calc, min/max precedence and box sizing.

Thirteen layout tests and a CLI golden fixture exercise this slice. The width
conservation test independently checks 120 combinations. Anonymous boxes,
vertical flow, fragments, text shaping and painted images remain unimplemented.
The progress catalog assigns only partial geometry/block-width credit; its full
engine denominator and existing completed capabilities are unchanged.
