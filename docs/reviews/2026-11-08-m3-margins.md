## Implemented

REN-02a removes the block reference's nonzero-vertical-margin refusal. It now
supports adjoining sibling margins, eligible parent/first-child and
parent/last-child margins, and collapse through empty auto/zero-height blocks.
Signed struts preserve the greatest positive and most negative member across
nested groups. Root/flow-root, borders/padding, fixed heights and the special
nonzero-minimum-height rule enforce the appropriate boundaries. Percentage
margins resolve against containing width; horizontal margins never collapse.

An empty box retains the border position prescribed by CSS 2.2 §8.3.1, rather
than being moved to the position of its following sibling. A negative auto
content height clamps to zero. Existing used-height, border-box, percentage,
RTL and overflow geometry behavior is retained. The old zero-margin CLI golden
fixture remains unchanged; a new signed/empty/parent-child fixture exercises
the expanded `dump-layout` behavior.

The implementation separates top-down containing constraints, bottom-up height/
margin resolution and top-down absolute placement. Each pass is bounded and
iterative. Relative child positions avoid repeated subtree translation. Node,
box, depth, text, output and coordinate limits, cancellation and atomic failure
remain enforced. No browser engine or dependency was added. Inline/anonymous
flow, shaped text, special/replaced content, positioning/floats/clearance,
overflow semantics and painting remain explicitly unfinished.
