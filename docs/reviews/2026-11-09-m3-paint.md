# M3 first paint and raster checkpoint — 2026-11-09

Continues `feature` after the M3 review fix (TD-40).

## Implemented

REN-04a/REN-05a add `rustic-paint` (display list) and `rustic-raster` (CPU
rasterizer and PNG), following the crate split in ARCHITECTURE.md. The block
reference layout now renders: canvas background with root/`body` propagation,
block background colors clipped to `background-clip`, and solid borders.
`rustic dump-paint` and `rustic render --output <png> [--scale N]` expose them.
[PAINT.md](../PAINT.md) is the contract.

## Safety and portability

No `unsafe`, platform API or dependency. Surface size, bytes, raster work,
display items and PNG size are checked before allocation or output, with
cancellation and atomic failure. Coverage and compositing use only IEEE `f64`
arithmetic, so the golden PNG checksum is checked on x64, ARM, 32-bit,
big-endian and RISC-V runs alike.
