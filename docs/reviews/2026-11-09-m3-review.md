# Review of the M3 start commits — 2026-11-09

Reviews `a1e82bb`..`b204a88` on `main`/`feature` (style invalidation fix,
REN-01a geometry and principal boxes, REN-01b block flow, REN-02a margin
collapse, REN-01c anonymous flow boxes) for correctness, resource safety,
platform portability and the technical debt rules.

## Findings

- **Fixed — TD-40 (Bad).** `BoxTree::build` cloned the DOM parent's whole
  `ComputedStyle` into every text box, and `FormattingTree::build` derived a
  new anonymous inline style per text run. A style is about 5 KB (69 longhands
  of 72 bytes plus heap values), so the default 100,000-box budget allowed
  about 1 GB of copies from a page whose text budget is 8 MiB. Styles are now
  shared `Arc`s; sibling text reuses the parent style and one anonymous inline
  style. Covered by `sibling_text_runs_share_one_parent_and_one_anonymous_style`.
- **Fixed — ledger order.** TD-36..TD-39 were added to the summary table in
  descending order and the TD-37 update sat under TD-38. Both are reordered.
- **Checked, no change.** The width equation (CSS 2.2 §10.3.3 with §10.4
  min/max reruns and border-box adjustment), the margin strut extrema model,
  parent-child/through collapse, the min-height exception, percentage heights
  against indefinite containing blocks and inline continuation splitting match
  the specification for the declared subset. All loops are iterative with
  explicit work/box/depth limits and cancellation; failures are atomic.
- **Checked, no change.** The `:nth-child(... of S)` full-restyle fallback
  (TD-36) is conservative and correct; structural changes outside the subject
  now reach descendants and following siblings.
- **Platform.** No `unsafe`, no platform APIs, no new dependencies; geometry is
  `f64` with explicit bounds, so results do not depend on pointer width or
  byte order. The sandbox run below covers 32-bit, big-endian and RISC-V.
