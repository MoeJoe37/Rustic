## Native Linux ARM64 record

The milestone needs the benchmark output and a passing heap fixture test from
a Linux ARM64 host. From a clean checkout of `feature` on that host, capture
the revision, toolchain, CPU and results together.

```bash
set -euo pipefail
test "$(uname -m)" = aarch64
{
  git rev-parse HEAD
  uname -sr
  rustc -vV
  lscpu
  cargo test --locked -p rustic-js --test limits the_heap_report_matches_the_committed_one -- --exact
  cargo run --locked --release -p rustic-js --example js_bench
} 2>&1 | tee js09-arm64.txt
```
