## Linux portability

Under QEMU 10.0.13 the 64-bit heap fixture matched on AArch64, RISC-V and
big-endian s390x. The deterministic heap-report test passed on 32-bit Armv7
and i686. The CLI integration suite passed on all five targets. The
AArch64, i686 and RISC-V CLI tests used isolated temporary directories on
rerun after file paths collided in the initial parallel runs.

All five targets also passed the rendering reftests at scales 1 and 2,
the fuzz seed replay and the `rustic info` smoke test. The 20,000-level
HTML nesting test passed on each target in a separate build with test
optimization level 1. The full 20-test JS-09 limits suite passed on
emulated ARM64.

The workspace all-target tests completed across the five Linux targets.
The totals combine the workspace runs and targeted reruns on the same source
revision. The ARM64 and s390x selector tests initially exceeded the
five-second wall-clock threshold during concurrent jobs. Both passed on reruns
with the original threshold and default test profile.

## Native Linux ARM64 record

TD-125 still needs the benchmark output and a passing heap fixture test from
a Linux ARM64 host. From a clean checkout of `feature` on that host, capture
the revision, toolchain, CPU and results together.

```bash
set -euo pipefail
test "$(uname -m)" = aarch64
{
  git rev-parse HEAD
  uname -sr
  rustc -vV
  lscpu
  cargo test --locked -p rustic-js --test limits the_heap_report_matches_the_committed_one -- --exact
  cargo run --locked --release -p rustic-js --example js_bench
} 2>&1 | tee js09-arm64.txt
```
